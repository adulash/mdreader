## Why MD Reader?

Most Markdown readers treat Arabic as an afterthought: broken alignment, wrong direction, scrambled lists and tables. **MD Reader** is built RTL-first. Open a file and it looks the way you wrote it: clear headings, tidy lists, and tables that start from the right. When the content is English, one button flips the direction.

Great for reading documentation, notes, and AI-generated Markdown — in Arabic or English.

## Features

| | Feature | What you get |
|---|---|---|
| ↔️ | **Arabic-first (RTL)** | Correct direction in both reading and editing, with a one-click direction toggle |
| 👁️ | **Two distinct modes** | Elegant formatted reading (the default) and direct editing — switch with `Ctrl+E` |
| 📊 | **Mermaid diagrams** | Rendered right inside the document, with independent zoom and drag-to-pan per diagram |
| 🌙 | **Dark mode** | Easy on the eyes, covering code blocks and diagrams too |
| 🎨 | **Syntax highlighting** | JavaScript, TypeScript, Python, Rust, Bash, JSON, HTML, CSS and more |
| 🔍 | **Zoom** | `Ctrl` with `+` / `-` or the mouse wheel; your zoom level is remembered |
| 🖨️ | **Print / PDF** | Print the formatted document or save it as PDF with `Ctrl+P` |
| 💾 | **Autosave** | Never lose your edits, and the app reopens your last file on startup |
| 📂 | **Open with** | Open your files straight from File Explorer |
| 🔒 | **Private by design** | Fully local: no internet, no accounts, no ads |

## Keyboard shortcuts

Shortcuts keep working when the Arabic keyboard layout is active.

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open a file |
| `Ctrl+S` | Save |
| `Ctrl+E` | Switch between reading and editing |
| `Ctrl+P` | Print / PDF (in reading mode) |
| `Ctrl+W` | Close the document |
| `Ctrl` and `+` / `-` | Zoom in / out |
| `Ctrl+0` | Reset zoom to 100% |
| `Ctrl` + mouse wheel | Zoom in / out |
